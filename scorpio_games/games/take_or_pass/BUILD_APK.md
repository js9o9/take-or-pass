# Build APK automatically

This project includes a GitHub Actions workflow at `.github/workflows/build-apk.yml`.

When the project is pushed to GitHub, the workflow:
1. Installs Java 17.
2. Installs stable Flutter.
3. Generates the Android platform project.
4. Downloads packages.
5. Runs `flutter analyze`.
6. Builds `app-release.apk`.
7. Uploads the APK as a GitHub Actions artifact named `take-or-pass-release-apk`.

Application id generated by the workflow: `com.scorpio.takeorpass`.
