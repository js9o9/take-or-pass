# خذها أو مرّرها 🎴

لعبة مسابقات عربية جماعية مبنية بـ Flutter، تعمل بنمط فردي أو فرق.

## المزايا في النسخة الحالية
- 4 مستويات صعوبة: مبتدئ، متوسط، محترف، متمرس.
- عدد لاعبين مرن، واسم «سكوربيو» افتراضيًا للاعب الأول.
- خيار الفرق يظهر عند وجود 4 لاعبين أو أكثر.
- 10 فئات: دول، حيوانات، دينية، عامة، سيارات، تقنية، تاريخ، أنمي، رياضة، ألغاز.
- بطاقات 100 / 200 / 300 / 400 / 500.
- توليد جولة مختلفة باختيار أسئلة عشوائية من بنك أكبر.
- يتذكر أسئلة الجولات السابقة ويحاول تقديم أسئلة غير مكررة أولًا.
- تلميحات خفيفة لفئتي السيارات والحيوانات.
- مؤقت 60 ثانية، تمرير السؤال، وكشف الإجابة.
- احتساب نقاط تلقائي وعرض ترتيب نهائي.
- حفظ آخر إعدادات اللعب وسجل مختصر للنتائج عبر SharedPreferences.
- أصوات محلية للإجابة الصحيحة والخطأ وانتهاء الوقت، مع زر كتم.
- لا يحتاج اتصال إنترنت لتشغيل الأسئلة أو الأصوات الحالية.

## التشغيل
1. ثبّت Flutter SDK.
2. لأن الحزمة الحالية تحتوي كود التطبيق والأصول فقط، ولّد ملفات المنصات مرة واحدة داخل المجلد:
   `flutter create --platforms=android,ios .`
3. ثم شغّل:
   `flutter pub get`
4. وبعدها:
   `flutter run`

## بناء Android
`flutter build apk --release`

## بناء iOS
يحتاج macOS + Xcode:
`flutter build ios --release`

> هذه الحزمة تحتوي المصدر، ولا تتضمن APK/IPA جاهز لأن بيئة إنشاء المشروع الحالية لا تحتوي Flutter SDK وXcode/Android SDK.
